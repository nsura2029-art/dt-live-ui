# Shell previews — 3 design directions (always in parity)

All three directions share **identical structure, navigation, pages, and behavior**.  
Only visual tokens (color, type, radius, shadow, gradient accents) differ.

| File | Direction | Font | Accent |
|------|-----------|------|--------|
| `design-1-editorial-shell.html` | Editorial / Swiss | Inter | Blue / violet |
| `design-2-soft-utility-shell.html` | Soft Utility | DM Sans | Sky |
| `design-3-monochrome-shell.html` | Refined Monochrome | IBM Plex Sans | Near-black |

## Shared shell features (must stay in sync)

- Sticky header + brand mark (clock) + wordmark / `dt.live`
- Log in + Sign up (gradient buttons) + placeholder pages
- Nav: Today, Holidays, On this day, Meeting finder
- **World Time** menu: World Time, Personal World Time, For Your Site
- **Timezones** menu: Timezone Converter, Timezone Difference, Daylight Saving Time
- Event Time, News
- Breadcrumb, footer columns, mobile menu
- Clickable links → `Clicked from [Header/Footer] → [Page Name]`

## Rule for agents / future tasks

**Whenever any shell or product feature changes, update Design 1, Design 2, and Design 3 in the same response.**  
Do not leave one direction behind.
